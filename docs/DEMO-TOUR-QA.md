# Globe tour

The plane control starts and stops an inventory-driven loop of up to eight geographically varied occupied cells. A fresh route is generated for every run. Close approaches are only assigned to verified occupied targets; empty inventory falls back to wide overview movement.

Normal stops last 24 seconds. Every generated route contains at least two detail stops when enough inventory exists; additional stops vary randomly. A detail stop adds a seven-second dive to altitude 0.24 and a six-second individual-cell view before pulling back. Camera movement and globe rotation ease continuously, with small bounded lateral variations. Exact topology and artwork detail load during the approach. The tour is opt-in even with reduced-motion preferences. Hidden tabs pause progression; manual pointer/wheel/keyboard interaction and resizing stop it.

Verification starts two tours and confirms that each target is an occupied cell, routes vary between runs, the plane changes to a stop control while active, and wheel input returns control to the visitor. Desktop and mobile screenshots must be inspected for artwork sharpness, framing, toolbar clarity and unobstructed interaction. Performance checks must confirm route generation does not add continuous per-frame work or unbounded retained data.

The tour uses a bounded 96-cell reservoir and yields periodically while scanning the one-million-cell occupancy texture. It retains at most eight stops and does no route-selection work in the animation loop. When inventory is empty, three wide overview stops are used and no close dive occurs.

Current verification: two consecutive starts chose different occupied target cells, manual wheel input stopped both runs, the production build and 18 desktop/mobile visual journeys passed without errors, and the active plane/stop toolbar state was visually inspected. The focused sample performance matrix retained its 128-page desktop and 64-page mobile cache limits with zero tile errors or unresolved fallback pages. Median sampled frame intervals were approximately 17 ms; the desktop moving-camera p95 was 33.9 ms and mobile p95 was 17.2 ms. These are local Chromium measurements, not physical-device certification.
